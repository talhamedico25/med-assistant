
# Med-Symptom Assistant (Python Version)

## Local Setup
1. Install requirements: `pip install -r requirements.txt`
2. Set API Key: `export API_KEY=your_key_here`
3. Run: `streamlit run app.py`

## Free Deployment (Streamlit Cloud)
1. Upload these files to a GitHub Repository.
2. Sign in to [share.streamlit.io](https://share.streamlit.io).
3. Connect your repo and click **Deploy**.
4. In **Settings > Secrets**, add: `API_KEY = "your_google_gemini_key"`
